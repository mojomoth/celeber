## 라운드 1 결함 재확인
1. 동명이인: 고침. `김민수` 4명이 따로 나오고(03), 배우·코미디언을 각각 확정하면 서로 다른 인물로 저장됨. 같은 후보를 다시 확정하면 같은 id.
2. 10MB 넘는 업로드: 고침. 19MB JPEG 200, 30MB는 화면에서 미리 막음(17), 37MB 413 한국어.
3. 실패 후 패널: 고침. 실패하면 패널이 닫히고 오류만 남음(14, 15, 17, 18).
4. SERPAPI 문구: 고침. 글자로 후보를 찾으면 "사진 검색을 쓸 수 없어 사진 속 글자만 확인했습니다."(11).
5. Esc: 고침. 첫 Esc는 목록만 닫고 값 유지. 지우기 버튼 하나(02).
6. 45MP: 화면 문구는 한국어로 감췄으나 원인(해상도)을 알 수 없음. API는 여전히 영어(core 미수정).
