## 공통 규칙

- **서체**: Pretendard Variable 하나만 쓴다. 화면 제목 30/800, 섹션 21/700, 행 15/500, 캡션 12.5.
- **헤더**: 탭 루트 화면은 `빈칸 · 제목 · 아이콘 1개`로 둔다. 뒤로 가기와 로고, 구분선은 두지 않는다.
- **하단 내비**: H&M 플로팅 pill을 응용했다. 4칸 모두 같은 폭에 아이콘과 10.5pt 라벨을 두고, 활성 칸은 회색 pill(`#EDEBE8`)로 채운다. 탭이 바뀌어도 아이콘 위치는 그대로다.
- **버튼**: Doji 페어를 따른다. 검정 채움과 1px 아웃라인, 높이 46, 반경 8, 간격 8. 버튼 페어는 화면마다 맨 아래에 한 번만 둔다.
- **사진 그리드**: 2열, 2pt 흰 이음새. 굵은 흰 라벨(28/800)은 왼쪽 아래 20pt에 두고 아래쪽에 스크림을 깐다. 밝은 배경 사진에는 잉크색 라벨을 위에 둔다. 04 드레이프 타일은 천 색이 왜곡되지 않도록 스크림과 라벨을 두지 않고, 색 이름을 타일 아래로 내린다.
- **색**: 잉크 `#25222B`, 종이 `#F6F4F0`, 선 `#ECE8E3`. 상태색은 확인 `#216652`, 주의 `#865018`, 위험 `#A13942`.
- **데이터**: 사용자는 봄 웜 브라이트이고, 정본 팔레트는 탠저린 · 코럴 · 피치 · 웜 틸 · 세이지 · 크림이다. 추구미는 한서도(가을 소프트)다.

## 다시 만들기

```bash
cd docs/ui/drafts/v4/_src
python3 gen.py jobs.json [id ...]   # 사진 생성 (gpt-image-2, 루트 .env의 OPENAI_API_KEY)
python3 render.py [02 03 ...]       # screens/*.html → ../NN-*.png (Chrome 헤드리스)
```

인물 사진은 모두 생성 이미지다. `refcrops/`의 v3 인물을 레퍼런스로 넣어 edit 방식으로 생성했고, 그래서 화면 간 동일 인물이 유지된다. `jobs.json`에 사진별 프롬프트가 있다.
