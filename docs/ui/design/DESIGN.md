# CELEBER 디자인 시스템

CELEBER는 촬영한 사진에서 피부색과 스타일 단서를 확인하고, 연예인 룩을 내 사진과 퍼스널컬러에 맞춰 적용하는 모바일 앱이다. 결과는 **사진 → 관찰한 특징 → 적용할 변화** 순서로 읽히게 한다.

## 레퍼런스에서 가져온 원칙

| 레퍼런스 | 공통 패턴 | CELEBER 적용 |
| --- | --- | --- |
| Doji · Revolut (01–04) | 어두운 촬영 화면, 한 줄 지시, 흰 프레이밍 가이드 | 환경·정면·측면·전신의 단계와 셔터 위치를 고정한다. 환경 결과에는 광원, 조도, 실내·실외를 보여준다. |
| ColorMo (05–06) | 사진과 원형 색 견본, 선택 표시가 있는 그리드 | 피부색 견본과 추천 의상색에 각각 이름을 붙인다. 사진 후보는 같은 비율로 정렬하고 선택한 사진에는 테두리와 체크를 함께 표시한다. |
| Instagram · H&M (07–08) | 인물 사진과 이름이 연결된 검색 결과, 사진 중심 탐색 | 검색 결과에서 인물을 먼저 선택한다. 대표·최근·평소 룩은 사진으로 훑는다. |
| SSENSE · Doji (09–12) | 중립 배경의 전신 사진, 썸네일, 선택 맥락 유지 | 실루엣과 소재가 보이는 사진을 우선한다. 분석 중과 사진 교체 중에도 현재 사진과 선택을 유지한다. |
| 퍼스널컬러 리포트 가이드 | 진단 요약, 얼굴 옆 드레이핑 비교, 적용 제안 | 요약에서 타입과 근거를 읽고 스크롤로 추천 의상색, 액세서리, 헤어, 그루밍을 확인한다. |

| 토큰 | 값 | 역할 |

| 종이 / 카드 | `#F7F5F0` / `#FFFDF8` | 보조 패널과 사진 캡션 바탕, 기본 카드 |

| 아이리스 / 진한 아이리스 / 옅은 아이리스 | `#7274E9` / `#4C45AD` / `#EEECFA` | BI 강조색, 밝은 바탕의 활성 텍스트·선택 테두리, 선택 배경 |
| 민트 / 라임 / 핑크 / 코럴 | `#50C89D` / `#D6F36C` / `#FF91BB` / `#FB603C` | Color Halo 배경, 브랜드 표현 |
| 촬영 바탕 / 촬영 보조 텍스트 | `#1D1B23` / `#C9C4D0` | 카메라 크롬, 역상 설명 |
| 상태 텍스트 | `#216652` / `#865018` / `#A13942` | 촬영 조건 확인, 재촬영 안내, 데이터 초기화 |

리포트의 피부색과 추천 컬러는 사진마다 바뀌는 데이터다. 여름 쿨 뮤트 시안에서는 더스티 블루 `#91A6BE`, 라벤더 그레이 `#A7A0B9`, 소프트 네이비 `#39455E`, 모브 `#9B748A`를 예시로 사용했다. 색마다 이름을 함께 표기한다. 웜·쿨 비교는 색과 텍스트로 표시한다.

## 서체와 간격

| 요소 | 크기 / 줄 높이 | 웨이트 |
| --- | --- | --- |
| 랜딩 로고 | 가로 184 pt, 원본 종횡비 | BI 벡터 |
| 화면 제목 | 32 / 39 pt | 700–800 |
| 섹션 제목 | 21–22 / 28 pt | 700–750 |
| 행 제목 / 버튼 | 15–16 / 22 pt | 600–700 |
| 본문 / 캡션 | 14 / 21 pt · 12 / 17 pt | 400–500 |

한국어는 시스템 산세리프와 Apple SD Gothic Neo를 사용한다. 모바일 기준 너비는 390 pt, 좌우 여백은 24 pt다. 기본 간격은 4·8·12·16·24·32 pt, 카드 모서리는 16 pt, 사진 모서리는 12–16 pt, 버튼 높이는 52 pt를 기준으로 한다. 헤더·탭·아이콘 등 조작의 터치 영역은 44 pt 이상 확보한다. 경계는 가는 선과 여백으로 표시한다. 랜딩과 카메라는 한 화면, 리포트와 가이드는 같은 너비의 세로 스크롤이다.

## 구성 요소

| 요소 | 규칙 |
| --- | --- |
| BI | 랜딩에는 `logo-on-dark.svg`를 사용한다. `color-halo-background.svg`의 빛과 BI 팔레트를 인물·드레이핑 이미지에 연결한다. 밝은 헤더는 `symbol-on-light.svg` 또는 `logo-on-light.svg`를 쓴다. [BI 에셋](../../../assets/bi/README.md) |
| 버튼과 탭 | 주 버튼은 잉크 바탕과 아이보리 텍스트다. 어두운 화면에서는 아이보리 버튼과 잉크 텍스트를 사용한다. 보조 버튼은 윤곽선으로 표현한다. 활성 탭은 아이콘·텍스트·강조 배경을 조합한다. |
| 카메라 | 네 단계 프리뷰, 한 줄 지시, 고정 셔터를 둔다. 환경에는 프레임 모서리, 얼굴에는 흰 윤곽, 전신에는 머리부터 발까지 들어오는 세로 프레임을 쓴다. 전신 단계에서 촬영·업로드·건너뛰기를 제공한다. |
| 리포트 | 사진과 주요 결론을 먼저 배치한다. 한 행에는 관찰 항목과 한 줄 결론을 둔다. 추천이 이어지는 곳에서 의상색이나 스타일 변화 예시를 보여준다. |
| 팔레트 | 같은 크기의 원형 견본과 색 이름을 묶는다. 얼굴 비교는 조명·표정·구도를 유지하고 목 주변 천의 색만 바꾼다. |
| 사진 선택 | 이름과 얼굴을 붙여서 표시한다. 역광·가림 등 분석 불가 사유를 짧게 표시하고 같은 인물의 다른 사진을 제시한다. |
| 추구미 기록·초기화 | 찾은 인물과 룩을 썸네일, 이름, 룩 이름 순으로 표시한다. 초기화는 실행 전 지워지는 사진과 진단 정보를 확인할 수 있게 한다. |

## 화면 흐름

| 화면 | 내용과 다음 행동 |
| --- | --- |
| [01 랜딩](../drafts/01-landing.png) | BI와 `시작하기`. 인물과 컬러 드레이핑을 한 장면에 담는다. |
| [02 나를 분석](../drafts/02-self-capture.png) | 환경 → 정면 → 측면 → 전신(선택). 환경에서 조명 조건을 확인한 뒤 얼굴을 촬영한다. 전신은 촬영하거나 업로드하고, 생략하면 결과에서 몸 비율을 `전신 사진 추가` 상태로 보여준다. |
| [03 내 분석 결과](../drafts/03-self-analysis.png) | 정면·측면·전신 묶음, 피부색, 얼굴 이목구비, 헤어, 몸 비율, 코디·액세서리 순으로 읽는다. `퍼스널컬러`와 `추구미 찾기`로 이동한다. |
| [04 퍼스널컬러](../drafts/04-personal-color.png) | 진단에 사용한 사진, 첫인상, 타입, 웜·쿨 비교, 명도·채도·대비 등 주요 특징을 보여준다. 얼굴 드레이핑 비교 다음에 추천 옷 색상·포인트 컬러, 액세서리, 헤어, 그루밍, 비추천 스타일을 이어서 배치한다. |
| [05 추구미 찾기](../drafts/05-style-muse.png) | 이름 검색 또는 사진 업로드. 업로드 사진을 분석할 수 없으면 같은 인물의 대표·최근·평소 사진 중 다시 고른다. 선택한 사진의 컬러와 코디를 보여주고, 내 팔레트를 기준으로 얼굴·코디·분위기 가이드를 제시한다. |
| [06 내 기록](../drafts/06-my-library.png) | 최근 찾은 추구미 목록에서 룩을 다시 열고, 내 퍼스널컬러를 다시 본다. 분석 정보 초기화는 확인 단계로 연결한다. |

시안 속 인물과 분석 결과는 생성 이미지와 예시 데이터다. 촬영과 진단 간에 같은 인물을 재사용하고, 추구미는 별도의 인물로 구분한다. 정면과 측면처럼 조작이 같은 단계는 같은 그리드와 버튼 위치를 공유한다.

## 시안 이미지 생성 프롬프트

내장 이미지 생성 도구에 아래 프롬프트를 사용했다. 생성한 배경과 사진 위에 실제 BI와 한글 UI를 배치해 PNG로 내보냈다.

| 화면 | 프롬프트 |
| --- | --- |
| 랜딩 | 모바일 화면을 가득 채우는 세로형 패션 화보. Color Halo 아이콘의 아이리스·제이드·코럴 빛과 ColorMo의 사진과 컬러 관계를 참고한다. 짧은 검은 단발의 가상 인물 주변을 더스티 블루·라벤더·코럴 실크가 크게 감싼다. 피부와 직물의 질감을 살리고 위아래는 로고와 버튼이 들어갈 어두운 공간으로 둔다. 사진 안에는 글자와 UI를 넣지 않는다. |
| 나를 분석 | Doji 촬영 앵글을 참고해 네 칸으로 나뉜 촬영 사진을 만든다. 좌상단은 커튼이 있는 창가, 우상단은 차콜 상의를 입은 가상 인물의 정면, 좌하단은 같은 인물의 오른쪽 측면, 우하단은 머리부터 발까지 보이는 전신. 네 칸은 중앙에서 나누고 사진에는 같은 중립 조명과 자연스러운 피부 질감을 적용한다. |
| 내 분석 결과 | 중립 배경에 둔 SSENSE·Doji 의상 사진의 구도를 참고한다. 따뜻한 회색 종이 위에 차콜 니트와 다크 차콜 바지, 작은 실버 링, 슬림한 은색 시계를 배치한다. 중앙을 가로로 잘라 써도 품목과 소재가 보이도록 촬영한다. |
| 퍼스널컬러 | 촬영 시안 정면 사진의 인물, 표정, 구도, 피부색, 조명을 기준으로 네 장을 만든다. 목과 어깨를 감싼 무광 천을 더스티 블루, 라벤더 그레이, 머스터드, 브릭 오렌지로 각각 바꾼다. 리포트 가이드의 얼굴 주변 비교 방식을 참고한다. |
| 추구미 찾기 | H&M·SSENSE·Doji의 구도를 참고해 같은 가상 배우의 네 장을 만든다. 블랙 재킷과 실버 귀걸이의 상반신, 테일러링 전신, 네이비 셔츠를 입은 평소 룩, 창가 역광으로 얼굴을 읽기 어려운 업로드 사진을 각각 한 칸에 둔다. |
| 내 기록 | H&M·SSENSE의 화보 구도를 참고해 쿨 그레이 니트의 가상 인물, 네이비 재킷의 또 다른 가상 인물, 라벤더 원단과 은색 귀걸이, 더스티 블루 상의와 슬레이트 바지 스타일을 네 칸에 담는다. |
