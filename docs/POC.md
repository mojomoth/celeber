# Celeber PoC(Proof-of-Concept)

내 얼굴과 전신등 사진을 업로드하여 퍼스널 컬러 진단과 내가 좋아하는 연예인 추구미 가이드를 받을 수 있는 앱의 기능 프로토타입

## Purpose
본 개발을 하기 전에 각 기능별로 구현하여 확인

## Stack
  - Next.js
  - Sqlite 
  - .env 에 필요한 API KEY 

## 내얼굴과 환경을 카메라로 촬영하여 최대한 객관적인 피부색과 얼굴 윤곽 추출
  - pocs/camera-face
  - 환경 촬영은 빛과 실내/실외 여부 분석을 위해 
  - 카메라 촬영은 정면과 측면 촬영
  - 촬영은 각 단계별로 진행
  - 피부색 추출 
  - 얼굴 윤곽 추출 

## 내 전신 사진 업로드하면 비율 측정
  - pocs/cameara-body
  - 내 전신 사진 업로드 하면 비율 측정 
  - 비율을 그래픽으로 직관적으로 표시 

## 연예인 사진을 업로드하여 검색 
  - pocs/search-celeb
  - 연예인이 누구인지 검색
  - 검색된 연예인의 유명/최근/평소 코디를 알 수 있는 전신 샷

## 연예인 코디와 퍼스널컬러 등 추구미 추출 
  - pocs/celeb-vibe
  - 업로드한 사진에서 추구미를 추출
  - 연예인의 코디 
  - 연예인의 퍼스널 컬러 
  - 연예인의 분위기

## 내 얼굴과 전신(Optional)에서 퍼스널 컬러 추출
  - pocs/personal-color-report
  - 선행 확인 
    - pocs/camera-face
    - pocs/cameara-body
  - 퍼스널컬러 리포트 
    - 업로드한 사진
    - 첫인상 브리핑
    - 퍼스널컬러 타입
    - 웜톤 vs 쿨톤 분석
    - 주요 특징 분석
    - 톤 컬러 적용 예시 (얼굴 주변)
    - 추천 옷 색상
    - 추천 포인트 컬러
    - 추천 악세사리
    - 추천 헤어 컬러
    - 그루밍 제안
    - 비추천 스타일
  - 분석된 가이드는 시각적으로 표현 
  - docs/ui/personal-color-report-guide/navy-men-personal-color-report-card.jpeg 참고 

## 내 얼굴과 전신(Optional)에서 퍼스널 컬러 분석 레포트에서 연예인 추구 가이드 받기
  - pocs/celeb-vibe-report
  - 선행 확인 
    - pocs/search-celeb
    - pocs/celeb-vibe
    - pocs/personal-color-report
  - 연예인 검색 및 사진 업로드 
  - 연예인 사진에서 분석된 퍼스널컬러와 코디 등
  - 연예인 사진에서 분석이 불가할때 동일 연예인의 검색된 사진에서 선택 
  - 추구미 가이드 
    - 얼굴 (헤어, 메이크업 등)
    - 코디 가이드 (분석된 내 퍼스널컬러 코디를 기반으로)
    - 분위기 가이드
  - 분석된 내 정보와 연예인 추구미 사이의 갭 확인 
  - 연예인 추구미로 변화할 수 있는 얼굴/코디/분위기 분석 
  - 분석된 가이드는 시각적으로 표현
