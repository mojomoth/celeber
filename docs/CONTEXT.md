# Celeber

내 얼굴과 전신등 사진을 업로드하여 퍼스널 컬러 진단과 내가 좋아하는 연예인 추구미 가이드를 받을 수 있는 앱 

## Screens 

1. 랜딩화면 
  - BI (로고)
  - 시작 버튼
  - 앱의 기능을 짐작할 수 있는 감각적인 배경화면 
  - Slop 텍스트 없이 심플하게 

2. 나를 분석 
  - 카메라로 환경 촬영: 광원과 주변 조도 예측을 위한
  - 카메라로 내 얼굴 촬영: 정면과 측면 촬영
  - 옵션으로 내 전신 촬영 또는 업로드: 내 몸의 비율을 확인하기 위한 

3. 나를 분석 결과
  - 리포트 형태로 직관적이고 심플하게
  - 촬영된 얼굴과 전신의 사진을 정돈
  - 분석된 피부 톤
  - 분석된 얼굴 이목구비
  - 분석된 헤어 스타일 
  - 분석된 몸의 비율 
  - 분석된 코디와 악세사리 등
  - 분석 결과에서 '퍼스널컬러' 진단과 '추구미 찾기' 이동 

4. 퍼스널컬러
  - 퍼스널컬러 리포트 
    - 업로드한 사진
    - 첫인상 브리핑
    - 퍼스널컬러 타입
    - 웜톤 vs 쿨톤 분석
    - 주요 특징 분석
    - 톤 컬러 적용 예시 (얼굴 주변)
    - 추천 옷 색상
    - 추천 포인트 컬러
    - 추천 악세사리
    - 추천 헤어 컬러
    - 그루밍 제안
    - 비추천 스타일
  - docs/ui/personal-color-report-guide/navy-men-personal-color-report-card.jpeg 참고 

5. 추구미 찾기
  - 연예인 검색 및 사진 업로드 
  - 연예인 사진에서 분석된 퍼스널컬러와 코디 등
  - 연예인 사진에서 분석이 불가할때 동일 연예인의 검색된 사진에서 선택 
  - 추구미 가이드 
    - 얼굴 (헤어, 메이크업 등)
    - 코디 가이드 (분석된 내 퍼스널컬러 코디를 기반으로)
    - 분위기 가이드

6. 기타
  - 검색된 추구미 리스트업
  - 분석된 내 정보 초기화
  - 내 퍼스널컬러 다시보기

## Function

1. 내얼굴과 환경을 카메라로 촬영하여 최대한 객관적인 피부색 추출
  - 환경 촬영은 빛과 실내/실외 여부 분석
  - 카메라 촬영은 정면 측면 촬영
  - 피부색 추출 
  - 얼굴 윤곽 추출 
  - (optional) 내 전신 사진 업로드 하면 비율 측정 

2. 연예인 사진을 업로드하여 코디와 퍼스널컬러 등 추구미 추출 
  - 연예인이 누구인지 검색
  - 업로드한 사진에서 바로 추구미를 추출 가능 여부 확인
  - 검색된 연예인의 유명/최근/평소 컨셉 
  - 연예인의 코디 확인
  - 연예인의 퍼스널 컬러 확인 

3. 분석된 나의 정보(퍼스널 컬러)를 통하여 연예인 추구 가이드 받기
  - 분석된 내 정보와 연예인 추구미 사이의 갭 확인 
  - 연예인 추구미로 변화할 수 있는 얼굴/코디/분위기 분석 
  - 분석된 가이드는 시각적으로 표현
